# stc89c52 — STC89C52 单片机入门实验合集

基于 STC89C52（8051 内核）的 10 个入门实验，覆盖 GPIO、定时器、中断、串口、数码管、矩阵键盘、ADC/DAC。每个实验都是**单文件、自包含**的 C51 源码，不依赖任何第三方库，可以直接添加进 Keil 工程编译。

## 硬件环境

- **芯片**：STC89C52RC（8052 内核，8KB Flash，512B RAM）
- **晶振**：定时器/软件延时按 **12MHz** 计算；串口实验按 **11.0592MHz** 计算（串口波特率对晶振频率敏感，换晶振必须换 TH1 初值）
- **数码管**：共阴极，段选/位选经 74HC573 锁存（`dula = P2.6`，`wela = P2.7`）
- **LED**：低电平点亮（P1 口）

各实验的引脚假设写在每个文件**开头的注释块**里，换板子请对照原理图核对。

## 编译与下载（Keil C51）

1. Keil uVision（C51 版本）→ Project → New uVision Project，器件选 STC89C52（需安装 STC 官方器件包，或选兼容的 Atmel AT89C52）
2. 把实验对应的 `.c` 文件添加到 Source Group
3. Options for Target → Output → 勾选 **Create HEX File**
4. 编译（F7）生成 `.hex`，用 **STC-ISP** 串口下载到板子
5. 建议在 Keil 中把编码设为 UTF-8（Edit → Configuration → Editor → Encoding），否则中文注释会乱码

## 注意事项

- 实验 05~07 与实验 09 的**数码管位选码不同**（`0xFE/0xFD/0xFB` vs `0x7E/0x7D/0x7B`），它们原本就来自不同的板子接线，用哪个实验按哪块板核对
- 实验 02 的 T0 方式 1 需要手动重装初值，存在微秒级累计误差，演示够用；精确计时可用方式 2 自动重装
- 实验 03 已由旧版的"点亮 5ms"（看不见）改为**按一次翻转一次**，行为与旧版不同
- 软件延时 `delay_ms()` 是粗略值，实际时长随编译优化等级浮动；需要精确节拍的场合一律用定时器
